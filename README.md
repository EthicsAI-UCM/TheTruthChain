# TheTruthChain

Este repositorio contiene los archivos del proyecto para Ética de Datos e IA del grupo TheTruthChain. Los documentos están escritos usando [Typst](https://typst.app/).

Los documentos compilados se encuentran en la rama `documentos`, si quieres compilar los documentos en local basta con ejecutar el archivo `build.sh` (es necesario tener `typst` instalado).
